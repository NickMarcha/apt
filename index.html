Bragi apt repository

Packages for Bragi and the headless Deskflow server, for Raspberry Pi OS / Debian trixie on arm64.

Install

curl -fsSL https://nickmarcha.github.io/apt/install.sh | sh

Or by hand:

curl -fsSL https://nickmarcha.github.io/apt/bragi-archive-keyring.gpg | sudo tee /usr/share/keyrings/bragi-archive-keyring.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/bragi.sources >/dev/null <<EOF
Types: deb
URIs: https://nickmarcha.github.io/apt
Suites: trixie
Components: main
Signed-By: /usr/share/keyrings/bragi-archive-keyring.gpg
EOF
sudo apt update && sudo apt install bragi

Update

sudo apt update && sudo apt upgrade

Bragi's dashboard can do this too.
